# Fit a regression with a network metric

Fits a Bayesian regression with the brms package in which a network
metric, such as node strength or edge weight, is a response or
predictor. The uncertainty in the metric, estimated by the edge model,
is carried into the regression by multiple imputation. Use it after
[`bison_model()`](https://bisonr.org/reference/bison_model.md) to test
hypotheses about edges, nodes or whole networks, for example whether age
predicts node strength.

## Usage

``` r
bison_brm(
  formula,
  edgemodel_list,
  data_list,
  num_draws = 100,
  z_score = FALSE,
  cores = 4,
  chains = 2,
  scale = c("none", "centre", "z"),
  subset = NULL,
  ...
)
```

## Arguments

- formula:

  A brms formula containing one `bison()` term (see *Details*).

- edgemodel_list:

  A fitted `bison_model` object, or a list of them for an analysis of
  several networks.

- data_list:

  A data frame of regression variables, or a list of data frames with
  one per edge model, in the same order. For edge and node metrics, each
  row refers to a dyad or node, and the columns named in the `bison()`
  term must hold node names that match the edge model. For global
  metrics, give one data frame with one row per edge model.

- num_draws:

  Number of posterior draws of the network metric to use, which is the
  number of regressions fitted. 100 is a reasonable value for a final
  analysis; smaller values (such as 5 or 10) are useful while developing
  a model.

- z_score:

  If `TRUE`, standardise the network variable within each posterior
  draw. Equivalent to `scale = "z"`.

- cores:

  Number of processor cores to use.

- chains:

  Number of MCMC chains to run for each regression. MCMC (Markov chain
  Monte Carlo) draws samples from the posterior; a chain is one
  independent run of the sampler.

- scale:

  How to transform the network variable within each posterior draw:
  `"none"` (default), `"centre"` (subtract the mean) or `"z"` (subtract
  the mean and divide by the standard deviation). For edge and node
  metrics, transformations are applied across the rows used in the
  model, separately for each network, which removes differences in the
  average level between networks; use `"none"` to compare levels between
  networks. Global metrics have one value per network, so they are
  transformed across the networks.

- subset:

  An optional logical expression, evaluated in each data frame,
  selecting the rows to use, e.g. `subset = sex == "F"`. Network metrics
  are still calculated from the whole network; only the rows of the
  regression are selected. Not available for global metrics.

- ...:

  Additional arguments passed to
  [`brms::brm_multiple()`](https://paulbuerkner.com/brms/reference/brm_multiple.html),
  such as `family` or `prior`.

## Value

A fitted brms model (a `brmsfit` object) combining the fits to all
imputed datasets. Use
[`summary()`](https://rdrr.io/r/base/summary.html),
[`brms::conditional_effects()`](https://paulbuerkner.com/brms/reference/conditional_effects.brmsfit.html)
or
[`brms::hypothesis()`](https://paulbuerkner.com/brms/reference/hypothesis.brmsfit.html)
on it as for any brms model.

## Details

The network metric is written in the formula as a `bison()` term
containing the metric and the data columns that identify its targets:

- `bison(edge_weight(node_1_id, node_2_id))` for dyadic regression;

- `bison(node_strength(node_id))`, `bison(node_degree[0.2](node_id))`
  and so on for nodal regression;

- `bison(global_cv(bison_network))` and so on for global metrics, with
  one row of data per network.

The `bison()` term can be on either side of the formula, and the rest of
the formula uses ordinary brms syntax, including random effects such as
`(1 | mm(node_1_id, node_2_id))`. In the fitted model, the network
variable is named after the metric, such as `bison_node_strength`. See
[`extract_metric()`](https://bisonr.org/reference/extract_metric.md) for
the metrics available.

Multiple imputation repeats an analysis on several plausible versions of
the data and combines the results. Here, each version uses one posterior
draw of the network metric (see
[`bison_mice()`](https://bisonr.org/reference/bison_mice.md)).
[`brms::brm_multiple()`](https://paulbuerkner.com/brms/reference/brm_multiple.html)
fits the regression to each version and combines the posterior draws of
all the fits, so `num_draws` regressions are fitted and fitting time
grows with `num_draws`. Models are fitted with the cmdstanr backend
unless `backend` is given in `...`.

Edge weights are used on the link scale (log-odds for binary models, log
rates for count models). Node and global metrics are calculated from
edge weights on the natural scale.

With a list of edge models, a factor `bison_network` is added to the
data, giving the position of each edge model in the list. It can be used
as a predictor or random effect to compare networks.

## See also

[`bison_brm_get_prior()`](https://bisonr.org/reference/bison_brm_get_prior.md)
to see and set the priors of the regression,
[`bison_mice()`](https://bisonr.org/reference/bison_mice.md) for the
imputed data, and
[`extract_metric()`](https://bisonr.org/reference/extract_metric.md).
