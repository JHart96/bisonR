# Print information about an edge mixture model

Print information about an edge mixture model

## Usage

``` r
# S3 method for class 'summary.bison_mixture'
print(x, digits = 3, ...)
```

## Arguments

- x:

  An S3 edge mixture model summary.

- digits:

  Number of digits to round summary values to.

- ...:

  Additional arguments to be passed to print functions.
